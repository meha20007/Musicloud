# 🎵 MusicLoud – Music Library Management System

MusicLoud is a cloud-based music library management system that allows users to explore songs, manage their music collection, and create playlists through a simple, user-friendly interface.

## 🌐 Live Links
- Website LINK : https://musicloud-1.onrender.com

## ✨ Features
- User registration and login
- Browse and search songs
- Add, update, and delete songs
- Create and manage playlists
- Cloud-based data storage

## 🛠️ Technologies Used
- Java Swing
- React.js and Vite
- Java Spring Boot
- Supabase PostgreSQL
- REST APIs
- Render

## 🏗️ Architecture
Frontend → Spring Boot Backend → Supabase PostgreSQL

## 🚀 Run Locally

**Web frontend:**
```bash
cd web
npm install
npm run dev
```

**Desktop application:** Open the Java project in NetBeans or IntelliJ and run the main class.
